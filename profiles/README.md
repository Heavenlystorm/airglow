# Community profiles

Lighting profiles you can browse, preview and install from Airglow (Lighting, Profiles, Browse). Each file is one
profile; [`airglow/profiles.py`](../airglow/profiles.py) describes the format.

**Sharing yours:** in Airglow, open Profiles, Edit, and press Share next to a profile. GitHub opens with the file
filled in; save it and GitHub proposes it as a pull request. It's checked automatically and appears in the gallery
once it's merged. Profiles are data only (colours, effects, an optional fan curve and automations), never code.

`index.json` is rebuilt by a workflow after every merge; don't edit it by hand. `featured.json` lists the profiles
shown first.
